# 后台管理真实资产、版本与模型接入 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让 `/model-governance` 展示并管理真实提示词、模型和路由；已发布版本只读，新版本可编辑；模型 API Key 加密入库；通过连接测试和审核的发布配置成为开发/测试环境的真实运行时来源。

**Architecture:** 继续复用现有 `GovernanceDraft → GovernanceVersion → GovernanceRelease`、`ModelGovernanceStorage` 和 `ModelGateway`。在现有治理存储中补密钥和连接测试证据，在 `model_service` 增加一个运行时解析模块；没有活动发布时保留当前代码/环境变量作为兼容回退，一旦存在活动发布则失败关闭，禁止静默绕回旧配置。前端继续使用现有工作区组件，以“每个资产一行 + 详情抽屉”合并代码基线、工作草稿、活动版本和历史版本，不另建第二套管理体系。

**Tech Stack:** Python 3.12、FastAPI、Pydantic v2、PostgreSQL/内存存储、`cryptography.fernet`、Next.js 16、React 19、TypeScript、Vitest、Playwright。

---

## 实施约束与成功标准

- 环境由 `MODEL_GOVERNANCE_ENV` 指定，只接受 `dev`、`test`，默认 `dev`。
- 所有已登录人员都能读后台；本轮不实现角色权限配置页。写、审核、发布仍沿用现有开发身份权限，后续权限管理再替换。
- 活动版本不可直接修改。任何修改都必须复制活动版本为新草稿，旧版本在新版本发布前持续生效。
- 模型草稿允许在未测试时保存；模型发布必须有与“模型内容哈希 + 当前密钥指纹”完全匹配的成功连接测试。
- API Key 只以密文存储，任何 GET/响应、日志、异常和前端回填都不得出现明文。
- 没有治理发布时，提示词和模型调用行为与当前代码一致；存在治理发布后，解析/解密/引用失败必须显式报错，不得静默回退。
- 提示词、模型、路由页即使没有草稿也展示真实代码基线；活动提示词能看到完整内容。
- 验证严格按 T1 单元测试 → T2a API 测试 → T2b Flow 测试 → T3 性能 → T4 E2E 的顺序执行。

def list_versions(self, asset_id: str) -> list[GovernanceVersion]:
    return self._storage.list_versions(asset_id)

def create_next_version(
    self,
    asset_id: str,
    *,
    actor: str,
    environment: GovernanceEnvironment,
) -> GovernanceDraft:
    active = self._storage.get_active_release(asset_id, environment)
    if active is None:
        raise ModelGovernanceGateError("资产没有可复制的活动版本")
    return self.create_draft(self._storage.get_version(active.version_id).content, actor=actor)

- [ ] **Step 3: 增加一个最小运行时解析函数**

`governance_runtime.py` 不建立新 Protocol，只复用现有存储工厂：

```python
class GovernanceRuntimeError(RuntimeError):
    pass

def current_environment() -> GovernanceEnvironment:
    value = os.getenv("MODEL_GOVERNANCE_ENV", "dev")
    try:
        return GovernanceEnvironment(value)
    except ValueError as exc:
        raise GovernanceRuntimeError(f"不支持的治理环境: {value}") from exc

def render_governed_prompt(
    asset_id: str,
    *,
    variables: dict[str, str],
    fallback_system: str,
    fallback_user: str,
    storage: ModelGovernanceStorage | None = None,
    environment: GovernanceEnvironment | None = None,
) -> GovernanceAssetPreview:
    store = storage or get_model_governance_storage()
    active = store.get_active_release(asset_id, environment or current_environment())
    if active is None:
        content = PromptAssetContent(
            asset_id=asset_id,
            name=asset_id,
            scene="fallback",
            system_prompt=fallback_system,
            user_prompt_template=fallback_user,
            variables=[PromptVariable(name=name) for name in variables],
        )
    else:
        content = store.get_version(active.version_id).content
        if not isinstance(content, PromptAssetContent):
            raise GovernanceRuntimeError(f"活动资产不是提示词: {asset_id}")
    return preview_asset(content, variables)
```

捕获存储异常时的规则：只有“没有活动 release”可走 fallback；已经找到活动 release 后的任何错误都包装为 `GovernanceRuntimeError` 抛出。

`scripts/model_governance_credentials_migration.sql` 与 `MODEL_GOVERNANCE_TABLE_SCHEMA` 使用一致的、可重复执行的 DDL：

```sql
CREATE TABLE IF NOT EXISTS model_governance_credentials (
    credential_id VARCHAR(128) PRIMARY KEY,
    encrypted_api_key TEXT NOT NULL,
    secret_fingerprint CHAR(64) NOT NULL,
    revision INTEGER NOT NULL,
    updated_by VARCHAR(128) NOT NULL,
    updated_at TIMESTAMPTZ NOT NULL
);

CREATE TABLE IF NOT EXISTS model_governance_connection_tests (
    test_id UUID PRIMARY KEY,
    asset_id VARCHAR(128) NOT NULL,
    content_hash CHAR(64) NOT NULL,
    credential_fingerprint CHAR(64) NOT NULL,
    succeeded BOOLEAN NOT NULL,
    latency_ms INTEGER NOT NULL,
    safe_message VARCHAR(500) NOT NULL,
    tested_by VARCHAR(128) NOT NULL,
    tested_at TIMESTAMPTZ NOT NULL
);
CREATE INDEX IF NOT EXISTS idx_governance_connection_success
ON model_governance_connection_tests
    (asset_id, content_hash, credential_fingerprint, tested_at DESC)
WHERE succeeded = TRUE;
```
