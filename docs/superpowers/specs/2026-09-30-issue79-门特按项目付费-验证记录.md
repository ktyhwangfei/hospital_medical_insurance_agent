## 2. 与 Issue #78 住院套表流程的关系

Issue #79 明确门特·按项目付费走**门诊套表**（`yb_mzjyxx`/`yb_mzfymx`，yllb='12'），与
Issue #78 实现的住院套表流程（`yb_zyjyxx`/`yb_zyfymx`，yllb='16'）互补。两套流程共用同一
确定性内核（`decompose_employee_outpatient_special`），快照适配层分离。mz 套表带来三个
住院套表没有的关键数据：

1. **周期/年度累计证据**（`yb_dyxxtsb`/`yb_dyxxnd`，医保中心侧数据，含跨院累计）：
   `bnmcjylsh` == 本笔交易流水号 → 交易后快照；交易前口径 = 快照值 − 本笔账面：
   - 已交起付 A = `bqqfje` − 本笔 `ybnqfje`；
   - 分段绝对坐标 P = `bqljybnje` − 本笔 `tsbybn`（周期内医保内累计，含起付段）；
   - 年度统筹累计 = `bntczfje` − 本笔 `tczhf`；年度大额累计 = `bndezfje` − 本笔 `degwyzhf`；
   - 起付标准：`bnzqslj`（本年周期数累计）≤1 → 1300，否则 650。
   9 笔（2024 年）有行 → evidence_status=confirmed，周期上下文从「不可重建」升级为可独立重算；
   5 笔（2025 年）无行（该表 2025 年起未维护）→ unknown。
2. **资格字段**（Issue #79 手工验证结论，候选口径，签核前不升级）：
   - `cjjrdj` 军残等级：1-4 → "1-4" 组，5-6 → "5-6" 组，空/'0' → 无资格；
   - `gwydybz` 公疗标志：0=享受，1=不享受（与红名单相反）；
   - `cblb=61` → 社会化退休（退休补充大额段 60%），其他退休码 → 普通 50%。
   内核据此**独立计算**军残（ESP-DVET）与公疗（ESP-PMED）补助（住院套表流程字段未映射，
   保持 observed_only 不变）。
3. **特殊病医保内外划分结果**：`tsbybn`/`tsbybw`（+`ptybn`/`ptybw` 普通部分；本批全为 0，
   非零属 ESP-CAT-002 普通门诊处理，未支持，fail-closed 返回 unavailable）。

## 3. 样本验证要点（14 笔全部手工复核）

- djh=567（退休，军残 1-4 级）：起付 1300 + 统筹 91%；军残 = 起付×100% + 剩余自付×100%
  = 1300+211.50 = 1511.50 ✓；账面 `jczhfqf`=1300（军残起付部分）旁证。
- djh=609（退休，军残 5-6 级 + 公疗）：军残 = 1300×50% + (19.80−9.90)×50% = 654.95 ✓；
  公疗 = 起付线以下 1300×(95%−50%)=585 + 以上 max(0, 220×97%−200.20−9.90−654.95+1300×50%)=0
  → 585 ✓（Issue #79 公式逐字实现）。
- djh=675（退休，无军残 + 公疗）：公疗 = 650×95% + max(0, 4433×97%−4034.03−199.49)
  = 617.50+66.49 = 683.99；账面 `gfylbchbx`=0 为**记录缺陷**——现金 165.49 = 650×5%+4433×3%
  与 `AGENCY_PAY_AMOUNT`=4917.51=4233.52+683.99 双重证明补助实际发生。差异如实保留，不凑平。
- djh=814（退休，军残 5-6 级）：交易前年度统筹累计 100000 已达封顶（`bntczfje`=100000.00
  实测）→ 免起付全额进大额（ESP-DED-004 数值首次可证）：大额退休 80% = 840 ✓，
  退休补助大额段 50% = 105 ✓，军残大额剩余 50% = 52.50 ✓。
- djh=708（社会化退休 cblb=61）：统筹段退休补助 50%（ESP-RSUP-003）= 68.31 ✓。
- 2025 年 5 笔（在职，恶性肿瘤门诊治疗 tsb1=502）：`dyxxtsb/dyxxnd` 无行，周期坐标不可得；
  账面 4 笔按 95%（4万-封顶段，ESP-RATE-104）、1 笔（2026452）按 85%（起付-1万段）。
  `tsbqsrq`=2024-09-03 + 360 天 = 2025-08-29：6-12/8-28 四笔在第 1 周期（累计已超 4 万 → 95%
  方向一致），9-23 在第 2 周期（坐标归零 → 85% 方向一致）。坐标数值跨院不可证 →
  守卫触发，统筹/大额 not_verifiable（不按坐标下界硬算；与封顶「未跨界可证明才可算」同一原则）。

## 5. 代码变更摘要

- 领域模型（`src/domain/insurance/fee_decomposition.py`）：`SpecialCycleContext` 增
  `prior_cycle_in_scope_total`（分段绝对坐标）；`SpecialPersonProfile` 增
  `military_grade`/`military_grade_raw`/`civil_medical_eligible`；快照增
  `segment_coordinate_guard`（评估口径开关，默认 False）。
- 内核（`employee_outpatient_special.py`）：分段坐标 confirmed 时用精确 P；
  坐标守卫（各段比例不同且坐标未知 → 统筹/大额 not_verifiable）；
  新增军残补助模块（ESP-DVET-001..004，在职自付原值/退休扣补助后剩余自付 × 档位比例，
  三部分分别取整）、公疗补助模块（ESP-PMED-001/002/004，起付线以下 F×(c−a) +
  以上 max(0, B×d−各基金支付−补助+F×a)，结算顺序 统筹/大额→退休→军残→公疗）；
  资格字段未映射的旧路径（observed_only）原样保留。
- 适配器/服务：mz 套表只读取数 + 交易后→交易前口径推导（负值矛盾降 unknown）+
  资格映射 + 非特殊病费用 fail-closed + fyfs 非 '0' 明确不支持。
- 测试：`test_special_mz_golden.py` 13 个黄金样本/纯函数用例（567/609/675/708/814/2025守卫/
  周期推导/资格映射）；既有 168 个门特+门诊分解测试全部保持绿色。
