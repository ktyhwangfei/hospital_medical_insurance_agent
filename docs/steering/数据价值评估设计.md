# 数据价值评估设计文档

> 版本: 1.0 | 状态: 建议方案 | 关联: 语义层-发现中心-质量分

---

## 1. 概述

当前质量分公式过于简单（`非空率×7 + 描述+1 + 样例+1`），无法体现数据活跃度和业务使用价值。本方案设计一套多维数据价值评估体系，每个维度可独立计算，最终加权汇总。

---

## 2. 评分维度与权重

| 维度 | 权重 | 满分 | 说明 | 数据来源 |
|------|------|------|------|----------|
| 非空率 | 50% | 50 分 | 数据是否充足 | `non_null_rate`（发现中心） |
| 字段描述 | 10% | 10 分 | AI 是否理解语义 | `description`（发现中心/Excel 导入） |
| 示例值 | 10% | 10 分 | AI 是否见过样本 | `sample_value`（发现中心） |
| 最近修改时间 | 15% | 15 分 | 数据是否活跃 | `last_updated`（发现中心/源表元数据） |
| 被引用次数 | 15% | 15 分 | 数据是否真正有价值 | `usage_count`（语义层指标） |

**总分范围**: 0–100 分

**等级划分**:

| 分数 | 等级 | 颜色 |
|------|------|------|
| ≥ 85 | A — 优质 | 绿色 |
| 70–84 | B — 良好 | 蓝色 |
| 50–69 | C — 一般 | 黄色 |
| 30–49 | D — 较差 | 橙色 |
| < 30 | E — 差 | 红色 |

---

## 3. 各维度计算规则

### 3.1 非空率（50 分）

```
非空率得分 = non_null_rate × 50
```

- `non_null_rate` 为 0–1 的小数（如 0.95 表示 95% 非空）
- 直接线性映射

### 3.2 字段描述（10 分）

| 条件 | 得分 |
|------|------|
| 有完整的字段描述（中文释义 ≥ 4 字） | 10 |
| 有描述但较简略 | 5 |
| 无描述 | 0 |

### 3.3 示例值（10 分）

| 条件 | 得分 |
|------|------|
| 有示例值且非 null | 10 |
| 无示例值 | 0 |

### 3.4 最近修改时间（15 分）

基于源表字段的 `last_updated` 或表的最后修改时间。

```
SELECT
  field_name,
  last_updated,
  CASE
    WHEN last_updated >= CURRENT_DATE - INTERVAL '7 days'  THEN 15
    WHEN last_updated >= CURRENT_DATE - INTERVAL '30 days' THEN 13
    WHEN last_updated >= CURRENT_DATE - INTERVAL '90 days' THEN 10
    WHEN last_updated >= CURRENT_DATE - INTERVAL '180 days' THEN 6
    WHEN last_updated >= CURRENT_DATE - INTERVAL '365 days' THEN 2
    ELSE 0
  END AS recency_score
FROM discovery_fields;
```

| 最近修改 | 得分 |
|----------|------|
| 7 天内 | 15 |
| 30 天内 | 13 |
| 90 天内 | 10 |
| 半年内 | 6 |
| 一年以上 | 2 |
| 从未更新 | 0 |

**建议**: `last_updated` 取自数据库系统表（如 SQL Server 的 `sys.dm_db_stats_properties` 或 PostgreSQL 的 `pg_stat_all_tables`）。

### 3.5 被引用次数（15 分）

| 引用次数 | 得分 |
|----------|------|
| ≥ 20 | 15 |
| 10–19 | 12 |
| 5–9 | 8 |
| 1–4 | 4 |
| 0 | 0 |

引用来源（当前仅支持指标级 `usage_count`，未来可扩展）：

```
引用次数 = SQL引用数 + 指标引用数 + Skill引用数 + API引用数
```

## 4. 最终公式

```
数据价值分 =
    非空率 × 50
  + 描述得分（10 | 5 | 0）
  + 示例得分（10 | 0）
  + 活跃度得分（15 | 13 | 10 | 6 | 2 | 0）
  + 使用度得分（15 | 12 | 8 | 4 | 0）
```

### Python 参考实现

```python
def calc_field_value_score(field: dict, usage_count: int = 0) -> dict:
    """计算字段数据价值分及各维度明细。"""
    nnr = float(field.get("non_null_rate", 0) or 0)

    # 描述得分
    desc = field.get("description") or ""
    desc_score = 10 if len(desc.strip()) >= 4 else (5 if desc.strip() else 0)

    # 示例得分
    sample = field.get("sample_value") or (field.get("sample_values") or [None])[0]
    sample_score = 10 if sample else 0

    # 活跃度得分
    last_updated = field.get("last_updated")
    recency_score = _calc_recency(last_updated) if last_updated else 0

    # 使用度得分
    usage_score = _calc_usage(usage_count)

    total = (
        round(nnr * 50, 1)
        + desc_score
        + sample_score
        + recency_score
        + usage_score
    )

    grade = (
        "A" if total >= 85 else "B" if total >= 70 else "C" if total >= 50
        else "D" if total >= 30 else "E"
    )

    return {
        "total": total,
        "grade": grade,
        "dimensions": {
            "non_null_rate": {"score": round(nnr * 50, 1), "raw": round(nnr, 4)},
            "description": {"score": desc_score, "has_desc": bool(desc.strip())},
            "sample": {"score": sample_score, "has_sample": bool(sample)},
            "recency": {"score": recency_score, "last_updated": last_updated},
            "usage": {"score": usage_score, "count": usage_count},
        },
    }


def _calc_recency(last_updated: str) -> int:
    from datetime import datetime, timezone, timedelta
    try:
        dt = datetime.fromisoformat(last_updated.replace("Z", "+00:00"))
        now = datetime.now(timezone.utc)
        days = (now - dt).days
        if days <= 7: return 15
        if days <= 30: return 13
        if days <= 90: return 10
        if days <= 180: return 6
        if days <= 365: return 2
        return 0
    except Exception:
        return 0


def _calc_usage(count: int) -> int:
    if count >= 20: return 15
    if count >= 10: return 12
    if count >= 5: return 8
    if count >= 1: return 4
    return 0
```

## 5. 实施路线

### Phase 1 — 当前（立即）
- 替换现有 `calc_field_quality` 为新的 `calc_field_value_score`
- 发现中心展示总分 + 等级
- 指标页展示引用度维度

### Phase 2 — 后续（依赖基础设施）
- 接入源表 `last_updated` 元数据 → 活跃度维度生效
- 指标 `usage_count` 接入 Skill 引用统计 → 使用度维度生效

### Phase 3 — 远期（语义层规模化后）
- SQL 引用数（从查询日志统计）
- API 调用次数（从 gateway 日志统计）
- 合并为统一 `usage_count`
