## 1. 设计目标纠正

**先解释原单已有的具体处理原因，再用项目限制性备注规定“还需要核对什么”，用诊断、检查、医嘱或检验事实核验。** 无需先取得医保原始响应，才能解释源库明确记载的原因或做项目条件核验；不能把“全自费”“特需”“目录等级3”直接作为终点。

自费标识说明结果，具体原因解释必须指出哪项事实或条件使本次未按通常方式支付。目录自付比例或等级存在，不代表用户已经理解原因，也不因此排除备注的价值。备注能明确病种、用途、机构或备案限制；还须说明本单相符、不符还是缺少哪项证据，未取得病历不等于不满足。

输出最少包含“本项承担多少—原单具体原因—本单证据—项目条件核验”。不是每笔都需要备注参与归因：已有欠费等整单记录时先如实解释，药品病种限制另行核验，不能把整单原因写成药品限制不符。备注的增量价值以是否让条件与事实更清楚衡量，不以是否参与金额计算衡量。

## 2. 样例一：艾普拉唑，备注与同处方诊断可核对

本单别名`eadf82c0aee0`，2026-04-16，ItemId4，项目`XA02BCA084B001010100453`，注射用艾普拉唑钠：金额52.60、医保内47.34、医保外5.26、SelfPay2为5.26，MEDIC_L为0.10。

| 核验材料 | 实际取得的证据 |
|---|---|
| 当日限制性备注 | 包含预防重症患者应激性溃疡出血、消化性溃疡出血两种情形 |
| 同处方诊断 | K27.400x004，消化性溃疡伴出血；已核费用与诊断RecipeNo相同 |
| 当前金额处理 | 5.26÷52.60＝10%，原SelfPay2字段与该数相同 |
| 原始证据粒度 | 同处方，不仅是同患者或同交易；不重复累加诊断关联后的费用行 |

[北京2025版目录官方PDF](https://ybj.beijing.gov.cn/zwgk/2024zcwj/202512/W020251230589322821268.pdf)第118页、谈判药西药第1项，列有上述限制，协议期2026-01-01至2027-12-31，和费用日期相容；本轮核到的是正文条目，不能只用旧院内快照认定当前规则。[官方执行文件](https://ybj.beijing.gov.cn/zwgk/2024zcwj/202512/t20251230_4378644.html)凡例另规定一般乙类先行负担及例外，具体支付体系仍随本单核对。

**本单有用的解释**：“这项52.60元记录SelfPay2为5.26元。目录限制包含消化性溃疡出血，本处方有相应诊断证据，因此支付条件中的诊断部分有支持，不能仅凭这10%就解释为病种不符合。当前10%的明细处理可再与本单适用的乙类先行负担规则核对。”

文字备注增加的是**诊断是否支持限定支付范围**，不是重新算5.26元。这是已取得事实的条件核验样例，尚不是“同一人前后自付波动原因已证实”的正例；此药在当前样本中没有相应波动配对。也不能从一条诊断推导所有法定适应证和实际治疗事实都已核实。

## 3. 样例二：西甲硅油，不能只看诊断，还要核对用途

本单别名`a1f3048c9526`，2026-04-17，ItemId6，项目`XA03AXX007X003010178278`：西甲硅油乳剂33.00元，医保内29.70、医保外3.30、SelfPay2为3.30。

| 核验材料 | 实际取得的证据 |
|---|---|
| 限制性备注 | 限胃肠镜检查和腹部影像学检查；官方2025目录第2页、西药第32项亦有该用途限制 |
| 同处方诊断 | R19.400，大便习惯改变 |
| 本单其他项目 | FPB01602电子胃镜检查410.00元；FPS01601电子结肠镜检查460.00元，均为正金额明细 |
| 当前金额处理 | 3.30÷33.00＝10%，不是全部33元自费 |

**只看诊断**：“大便习惯改变”不能证明属于限定检查用途，也不能据此判定药不符合医保条件。**把本单检查项目一起看**：已经存在明确的胃肠镜收费证据，可以支持继续核对检查用途，不能因诊断名未写“胃肠镜”就判为不符合。

可给出的回答是：“该药的支付限制针对使用用途。本单除了大便习惯改变诊断，还收取电子胃镜和电子结肠镜费用，存在与限定用途相关的证据。若药物与这次检查的医嘱/执行关联确认，该用途条件即可进一步核实；现有3.30元明细自付不应直接说成‘诊断不在限制范围’所致。”

边界：检查收费证明本单登记了检查费用，不等于检查已执行，更不自动证明该药用于该检查。当前未取得药物医嘱到具体检查的关联，结论为**用途有收费证据支持，关联待核**。本例没有已确认的自付比例波动配对；负数交易也不能不核原单关系就与本单合并。

## 5. 本轮还排除了哪些假证据

- 四链路罗沙司他16条全额医保外候选的同处方诊断及病历均为“1”，不能拿占位值证明慢性肾病相关贫血不符合。
- o_CheckResult_D与o_FeeItem_E保存的是诊断/单位缺失、处方取药时间等信息校验结果，不是临床检验值或药品限定支付符合性结论。
- 人工晶体、助听器限额封顶仍不作为项目内涵的价值正例；葡萄糖同院差异不能归因为指定医院限制。

## 6. 收敛后的实现与验收

在现有单单费用解释里，按用户所问项目取当日备注，列出能核验的原子条件，再用本单诊断、处方、收费及可用临床数据逐项对照。模型负责组织解释；编码、日期、关联键及金额由确定性逻辑核对。当前不增加跨单检索平台，不因本单缺信息自动查患者历史。

取数顺序增加最小一步：先取本单具体处理原因及对应源字典，再核项目条件。解释必须使用具体名称和本单金额；不能把PN_NoRightReason、txbz、tsbbs、tsbyybz等不同字段统一翻译为“特需”。复合原因不重复计算金额，缺少字段绑定或字典时不猜译。目录等级只给出处理类别时，说明已核实的备注条件及尚缺的具体事实。

| 条件核验状态 | 允许的解释 |
|---|---|
| 有对应事实支持 | 具体说明支持哪条条件，不推定未核条件 |
| 有明确反证 | 说明何项条件与事实冲突，提示核查；不能把临床资料缺失当反证 |
| 资料或关联不足 | 指明缺少哪一项，不泛写“证据不足” |
| 条件相同但处理不同 | 明确当前备注无法解释波动，不编造病情变化 |

验收重点：首先验证来自四条费用分解实际覆盖单据；艾普拉唑必须命中同处方诊断；西甲硅油不得仅看诊断下结论，也不得将收费当执行；罗沙司他不得把占位诊断当条件不符；住院白蛋白不混入门诊/门特样例；未来多单必须由用户显式选择。金额自付、医保内外与最终基金支付保持各自口径。

本轮[条件核验证据](../reviews/2026-11-02-issue85-condition-validation-evidence.json)保存同处方诊断、两条胃肠镜收费及白蛋白关联缺失结果；[两条只读复查SQL](../reviews/2026-11-02-issue85-condition-check.sql)已独立重读处方诊断及本单检查费用并通过核对。两条10%明细比例及诊断/检查存在性已核对，尚未形成真实波动原因的闭环正例。此前[目录样例证据](../reviews/2026-11-02-issue85-project-content-evidence.json)与[字段深查](../reviews/2026-11-02-issue85-deep-evidence.json)仍可复查。未修改运行时代码，独立临床审核尚未执行。

## 7. 患者解释与医保办核验分别验证价值（V9.0，未实施）

患者按具体疑问展示支付条件、本单事实及核对事项；已有比例足够回答金额问题时不强塞条款。医保办另验证“授权定位原单→针对性补证→复核关闭”的实际收益，不能因为患者归因正例不足就默认反向扫描值得建设。规则库、内部标准概念与映射方向保留，先有业务闭环证据再扩展自动化。

取数修正：旧门诊16行加入状态4且未退过滤后为12行、7码，FeeIn合计3,859.3120；门特另1行最终状态待核。[复查证据](../reviews/2026-11-04-issue85-adversarial-design-evidence.json)。FeeIn不是基金损失，诊断一对多不得重复计费。阿普米司特仅凭科室与占位诊断不能裁定高度可疑；西甲硅油收费仍不是执行/用途满足；支付标准不能统一当售价上限，须按适用政策核支付基数和实际划分。

患者理解、正确下一步和医保办总工时/有依据关闭均尚未实测。完整证据要求、三版本比较、独立复核、否证条件及实现边界以[运营设计V3.1](限制性备注合规核验-医保办运营解释设计-V1.0.md)为准；本节取代V8的样本计数、科室疑点裁定和平台切片描述。

| 本院机构等级 | 复用m_institution及既有字典名称 | 本院实际等级与目录限定原码分开，后者缺字典不猜译 |

| 其他本单收费名称 | 单行问题附带同单名称与类别，不携带其他行金额 | 胃镜等只能作用途核对线索，配合用药也不能由同单收费直接证明 |

接口新增可选fee_items[].payment_condition_context；旧字段、金额及分支不变，未算平行也可提供这些原始事实。两路补充查询独立降级，缺目录不抹掉可用的同单诊断；模型输入去掉读取哈希/时间等审计噪声。同单收费线索放在模型billed_items，不扩展费用计算范围。

实验固定同单、同问题和同一提示词，对比不提供/提供上下文；保存生成原文、出口是否采用、退回原因及模型名称。原始结果在[阶段1模型对比](../reviews/2026-11-04-issue85-stage1-model-probe.json)，初次探查另保留.initial.json。当前仅探索，正式业务效果仍按§7验证。

本轮接入与试验结论见[阶段报告](../reviews/2026-11-04-issue85-stage1-context-result.md)：六例金额/分支未改变；模型草稿出现具体核对方向，但最后一轮3份增强正文均被既有出口拒绝，患者解释增益尚未兑现。
