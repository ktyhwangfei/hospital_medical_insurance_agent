# 宽泛问题路由/拒答机制设计（#33 补强·供架构评审）

owner 知识 | 2026-09-03
对应：架构裁决「P@3 仅可经『把 broad 宽泛问题改为路由 structured 或确定性拒答』结构性替代，FAR=0+确定性拒答为不可破底线」。
范围：#33 门诊+通用（住院除外）。

## 1. 问题→路径映射（何时路由/何时拒答）
把 query 在入口按三类意图分岔，不再让 broad 直接自由检索作答：
- A 具体政策可定位（含明确 险种+医疗类别+行为：在职职工门诊三级报销比例）：→ **structured 精确路径**（域确凿，不必带 broad）。
- B 宽泛/泛指，但**语义落在本语料覆盖域内**（无险种/类别限定：医保门诊最高限额？）：→ **路由到 structured 按"该域最可能意图"取**，而非 broad 词面自由召回。路由命中指标 = 险种+诊疗类别+待遇对象的判别置信。
- C 涉及**语料外或无对应事实**的确定性拒答对象：废止(2023已废)/草案/未来版本/异地支付比例/本统筹区无此政策/住院类(范围纪律外)/参保人身份缺失不可推断 → **确定性拒答，答"本市/当前有效政策中未收录/不适用"**，绝不编造或取过宽片段兜底。

## 2. 判定依据（路由 B 与拒答 C 各一手）
- 路由 B 判据 = 意图分类器输出 (险种∈[职工,居民]×类别∈[就诊类型]×对象∈[在职/退休]×动作∈[报销比例/限额/待遇/资格])，任一缺但为"语义明确指向门诊" → 默认该域 all* 并在 structured 端做候选取合一；分类置信 < 阈值→不 free-return，改交 C 判。
- 拒答 C 判据（**版本/时效/地域三把硬刀**，知识口径）：
  1. 时间词(年份/已废止/新规/草案/未来) 与 effective/expiry 对不上 → 拒答(语义版本不存在，非过滤可判——过滤只裁 existing 语义)。注：#33 语料现全 published 无过期档，"废止/未来"连档都不存在 = 直接拒，不需事后 date 判断。
  2. 地域词于本市语料本不覆盖(上海/异地比例) → 拒答"异地就医结算/该统筹区不适用"。
  3. 住院术语 → 拒答(排除范围)，不落 broad。
- 由此 C 与加固②字段过滤互补：字段过滤拦截"存在但失效"的真实段(防御)；本机制拦截"根本不存在该档"的问法(语义补位)——正好覆盖 5 条版本类+异地+住院类负例。

## 3. 误路由兜底
- structured 命中候选为空 或 最高置信仍 < 拒答阈 → **不回落到 broad 自由检索**，直接走确定性拒答(诚实)。
- 路由只做"向上提升精确度"，无绝对把握一律拒而不是猜 broad；prima facie 宁可多拒几次不可答(retry 代价)也绝不让 broad 输出可能误导的宽泛片段。
- 每类端到端回归守卫：新增用例覆盖 A/B/C 三相 + 误路由/拒答过度/拒答不足三 fail 模式。

## 4. 保留
- structured FAR=0/诚实拒答确定性为底线不降；P@3 让位于「路由准确率(命中正确认)+ 误路由率 + 确定性拒答率」三口径(新 eval key)，broad 自由检索路径仅在 B 无结构性候选且 C 判可答(罕见)才兜底，标 audit 位。

## 交付形态
核心落在意图/路由层脚本+意图分类器配置+三判据守卫；与读路径(shared validity)解耦复用。待架构评审通过后按最小实现派工，T1 单元过三判据/路由函数，T2 端到端三向+兜底回归。
