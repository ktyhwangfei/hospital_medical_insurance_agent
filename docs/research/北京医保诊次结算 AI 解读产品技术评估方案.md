## 一、项目背景

当前北京市医保政策体系具有以下特点：

```
政策数量多更新频繁规则复杂存在大量“条件式规则”同一规则存在：- 法规口径- 解读口径- 医院执行口径
```

患者在医保结算过程中，经常产生疑问：

```
为什么我的起付线是1950？为什么别人报销比例比我高？为什么这次又重新收起付线？为什么同样是三级医院结果不一样？
```

传统医保系统只能展示结果：

```
总费用基金支付个人自付起付金额
```

但无法解释：

```
为什么这么算依据哪条政策触发了什么规则历史诊次如何影响本次结果
```

因此，本项目拟构建：

# “医保诊次 AI 解读引擎”

实现：

```
政策可检索规则可计算诊次可解释结果可追溯
```

---

# 二、项目核心目标

核心目标不是“医保聊天机器人”。

而是：

```
基于医保政策 + 患者诊次数据 + 规则计算实现医保结算结果的可解释化
```

重点解决：

```
患者看不懂经办人员解释困难政策口径复杂历史诊次关联困难
```

---

# 三、核心技术路线

本项目本质是：

```
RAG（政策知识库）+规则引擎+医保结算数据分析+AI解释生成+审计溯源
```

而不是：

```
直接把政策和数据丢给大模型
```

# 5.1 政策不等于规则（最关键）

医保政策本质是：

```
自然语言
```

而系统计算需要：

```
结构化规则
```

例如政策原文：

```
第二次及以后住院起付线减半
```

系统必须转换成：

```
{  "rule_name": "住院起付线减半",  "scene": "住院",  "condition": {    "hospitalization_count": ">=2"  },  "action": {    "deductible": "standard * 0.5"  }}
```

这一步：

# “政策规则结构化”

是整个项目最大的技术难点。

也是真正壁垒。

# 七、为什么“政策解读”极其重要（新增）

真正患者提问时：

```
患者不会问：“医保发〔2025〕xx号文件第六条怎么规定”患者会问：“为什么我这次比上次多扣650？”
```

因此：

|数据类型|适合用途|
|---|---|
|政策原文|权威规则依据|
|政策解读|AI自然语言解释|
|医院指南|实际业务口径|

最终 AI 回答必须融合：

```
法规依据+业务解释+患者数据+规则计算
```

# 九、政策规则结构化（新增核心章节）

这是整个项目最关键阶段。

---

## 9.1 目标

把：

```
政策自然语言
```

转成：

```
可执行规则
```

---

## 9.2 示例

政策原文：

```
住院治疗每90天为一个结算周期。第二次及以后住院，起付线减半。
```

结构化后：

```
{  "rule_type": "deductible_rule",  "scene": "住院",  "period_rule": {    "cycle_days": 90  },  "condition": {    "hospitalization_count": ">=2"  },  "action": {    "deductible": "standard * 0.5"  }}
```

---

## 9.3 必须抽取的信息

|信息|示例|
|---|---|
|适用人群|职工医保|
|医院等级|三级医院|
|场景|住院|
|条件|第二次住院|
|周期|90天|
|动作|起付线减半|
|例外情况|转院连续计算|
|生效日期|2025-01-01|

# 十、患者数据验证

## 10.1 核心问题

很多医保解释问题：

```
不是当前诊次问题而是历史诊次问题
```

例如：

```
1950 = 1300 + 650
```

系统必须关联：

```
历史住院记录年度累计起付线90天周期医院等级
```

否则无法解释。

---

## 10.2 必须验证的数据能力

|能力|是否必须|

|医保身份识别|必须|

# 十二、AI解释生成验证

## 12.1 大模型职责

大模型只负责：

```
理解问题组织语言引用政策生成解释
```

不负责：

```
最终金额计算
```

---

## 12.2 示例输入

```
{  "问题": "为什么起付线是1950？",  "规则计算结果": {    "首次住院": 1300,    "第二次住院减半": 650,    "累计": 1950  },  "政策依据": [    "第二次及以后住院起付线减半"  ]}
```

---

## 12.3 示例输出

```
您本次显示的1950元，并非单次住院起付线。根据您的历史住院记录，本年度已产生一次1300元起付线，后续住院符合“第二次及以后住院起付线减半”规则，因此额外产生650元减半起付线。累计为：1300 + 650 = 1950元。
```
