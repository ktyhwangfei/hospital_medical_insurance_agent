- 条件1：设计第4节「罕见 broad 兜底」第一版**默认关闭**——broad 自由检索不产出答案，只落 audit 记录；开门留档后续谈，不放出可用口子。
- 条件2：新 eval 三口径（路由准确率/误路由率/确定性拒答率）**先基线后门禁**——首轮只记录不定阈值，第二轮起再进门禁。

## 需要实现的三判据/路由函数 + 回归（最小）

### 模块落点建议
在既有读路径入口加一个路由判定层（优先复用现有 intent/路由既有脚本与 shared validity helper，勿新增store）。核心 = 把 query 分流 A/B/C：

### A. 三判据守卫（判断 query 属于 C 确定性拒答的场景）
1. 时间/版本判据：query 问"已废止/当年旧规/草案/未来年度/新规"，而语料(现全 published+expiry=9999)根本无此"时间档实体"→直接拒(带"本市现行政策未收录该(年度/版本)"类消息)。不做 date 事后判(那只裁 existing 无效段，和加固②互补：彼拦"存在但失效"真实段，此拦"根本不存在该档"的问法)。
2. 地域判据：query 明确非本统筹区(上海/异地支付比例/他市)——语料全为本市 → 拒"异地或他区不适用"。异地"备案流程"类(语料有)属 A/B 可答，只有"异地比例/待遇"才拒。
3. 范围判据：住院术语(住院分段/住院报销)在 #33(门诊+通用) → 拒"该范围暂未收录"，不落 broad。

### B. 三判据命中即 routing，把 C/B 误判兜底
- query 属宽泛但语义在本语料域(无明确险种/类别，如"门诊报销比例/最高限额")→ **路由到 structured** 取域内最可能意图(倾向职工/居民 all)，不用 broad 词面自由召回。
- 结构化候选为空 或 最高置信 < 拒答阈 → **回落确定性拒答(诚实)，绝不回落 broad 自由检索**(条件1)。audit 记录为该 query 的落点(C/A/B/broad-kept-closed)。
- 命名/结构：路由不重复造轮——命中判据允许列白名单规则查 "off"/"闭" 即处理。

### C. T1（单元，覆盖三判据函数 + 路由函数）
- 三判据各 ≥3 条：正常命中 / 阈值边缘(date"去年" vs "今年"边界)/ 空输入、异常值。
- 路由函数：A 直接 structured、B 路由 structured、C 拒答、结构化漏空→拒答；audit 位写对。条件1: broad 分支产出空 + 有 audit 记录。
- 复用一个测试目录，不与 structured/broad 单元路径冲突(可先 red 后 green)。

### D. T2（端到端三向 + 兜底回归）
- A/B/C 三向各自命中正确 final(端点返回对)；拒答消息含"不适用/未收录"语义。
- 既有 neg 负例集：凡 C 判拒答的不得再出 broad 答案(--断言不overhead)。
- 回归：structured FAR 0/诚实拒答 100 不回退；broad 现有 827(含前几轮) passed 不回退。
- eval：跑路由后的新三口径并**先记录不定标**(条件2)，同报告基线并列。

### 验收出口
- T1/T2 全绿(带证据数字)+ 新三口径基线记录 + broad 第一版兜底默认关闭(audit 演示一条)；commit Angular 规范，message 【路由拒答①】。
- 不回退 structured(FAR 0/拒答100) 与已交付加固①(空ctx拒答)。
完成回报：改动文件、用例数、各回归数字、新三口径首轮基线、audit 示例一条。门禁判定留给加固后统一复测。
