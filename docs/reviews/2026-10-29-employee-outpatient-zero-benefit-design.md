## 规则与范围

- 军残待遇等级 0 对应“不享受伤残待遇”，来源为现有 `semantic_layer/seed.py` 的 `MILITARY_DISABILITY_LEVEL`（原 `business_sql.yaml` CASE）。原始等级明确为 0 且与已知资格不冲突时，返回本笔不适用、计算值 0 和该等级条件。
- 原公疗待遇类别明确为 0 时，没有选择当前内核的原公疗补助通道。返回本笔通道未选择、计算值 0 和类别条件；不能把公务员待遇标志 0（享受）翻译成不享受，也不能推广为患者永久没有公疗资格。
- 当前通道条件来自既有 D6：`P_Official=0 AND P_OfficialCode=3`。本次仅接入明确的零分支，不开启候选资格派生总开关，不由非零/零支付反推资格，不自动推导正向公疗定点、军残资格期或退休补充日期。
- 缺失、陌生原始码保持未知；原始码与显式资格冲突时返回冲突缺证。已知不适用但原单非零时继续由现有核对逻辑标记冲突。
