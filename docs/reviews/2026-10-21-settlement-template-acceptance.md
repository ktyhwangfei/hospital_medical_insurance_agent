# 结算单标准模板接线与验收

日期：2026-10-21。范围：用户图片字段识别、四链路模板、数据库绑定、费用分解和结算解释右栏共用展示。

## 交付

- 识别图片 8 个基本信息字段、19 个金额字段及双列/跨列布局；不复制个人身份原文和单笔手写比例。完整识别与维护说明见 [结算单展示模板与字段映射](../steering/结算单展示模板与字段映射.md)。
- 四个 JSON 文件分别维护职工门诊、居民门诊、职工门特、居民门特。职工门特文件内独立定义定额变体。
- 首次由 AI 根据图片、既有列定义和快照组装生成匹配配置；运行时通过校验后的配置生成查询列、账面观测值和展示事实。仅接受安全列标识符，拒绝 SQL 表达式、重复键/计算目标、重叠布局和非法金额。
- 普通门诊的 RecordQueryMapping 院区列覆盖继续生效。门特总医保内/外与特殊病分项分别绑定；定额汇总与医院清算分开。
- 公开契约 1.8 下发安全模板与标准字段名；物理表列不下发。两处页面共用组件，窄栏单列、宽区双列；缺值和未映射分开显示，新版本缺模板时不猜测回退。
- 按模板标准名称提问会定位配置指定的计算字段。没有计算绑定的原单字段只携带账面事实，避免定额清算与患者费用串用。
