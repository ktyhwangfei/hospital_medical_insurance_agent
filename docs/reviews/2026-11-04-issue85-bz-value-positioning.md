# bz的价值：从信息增量到可独立验证的用户收益

2026-11-04，Issue #85，分析V2。设计落实见[运营设计V3.1](../steering/限制性备注合规核验-医保办运营解释设计-V1.0.md)。分开检验“原文有信息”“本单可判断”“用户实际获益”，不以平台规模代替分析深度。

## 1. 重写前的四个问题

**专家会额外做什么？** 先观察真实咨询和医保办办理过程，确定要改变的理解或行动，检查原系统已经做到什么；把补证、误报、误导及维护计入代价，主动设否证条件。加bz仍不能答对问题或完成复核，就不把“多一段解释/一套规则”当成功。

**从哪些最原始素材开始？** 当时有效的官方完整目录、凡例与地方文件；原结算、费用、退费链、原因及源字典；处方、医嘱、执行、同期病历/检验及必要既往记录；患者原咨询与追问；医保办已复核案卷、补证过程、原审核工具及工时日志。整理后的bz表、数据摘录和告警须回原件验证。

**具体方法和工具是什么？** 只读SQL核费用键、状态和关联基数，Decimal复算金额，来源快照与SHA-256锁定证据；逐条件审查版本、规格、AND/OR和触发前提；医保政策人员与临床药师独立盲审；比较现有流程、增加bz原文、增加条件证据解释三个版本，观察患者复述/行动、医保办结论和总人时。编码匹配只做归一，不能替代临床关系判断。

**除了你我怎样证明？** 官方条款证明规则，临床原记录与独立复核证明判断，可复算查询证明数据，真实任务与办理日志证明效果。四者不能互替；已支付、专家喜欢或模型自评均不足以证明产品价值。独立验证未执行，不能把要求写成已获结果。

## 2. bz提供什么增量

原Excel仅一列bz、2,058条非空去重文本，无编码、时点或险种，主要是药品限定支付和支付标准，不能整体当医疗服务项目包含操作/材料的“服务内涵”。哈希与11月2日一致。[原表位置、哈希及单元格证据](2026-11-04-issue85-bz-value-evidence.json)。

722条含支付标准、657条含机构词、287条含个人承担词、241条含字面[适]，是可重叠的关键词计数，不是规则数、项目数或收益。722条价格文字之前均另有“限”字，说明已有价格字段不等于整段重复；未证明各限定均适用于当前费用或已正确解析。

| 原表单元格 | 数值字段之外的信息 | 必须取得什么原始事实 |
|---|---|---|
| A1429，CKD引起的贫血 | 病种还含病因关系 | 同期病情及病因依据，不是两个诊断的交集 |
| A478，限胃肠镜/腹部影像 | 用途不由诊断名称单独决定 | 医嘱、执行、药物—检查关联 |
| A782，无法口服；A940，配合肠外营养 | 给药前提与配合使用 | 不能口服的同期记录；配液/执行关联 |
| A526，既往效果、BMI、首次资格 | 历史、阈值和触发前提 | 原病史、身高体重、首次性、机构/医师资格 |
| A366，不同规格对应病种；A710，指定机构 | 规格分支、机构角色 | 实际规格、有效目录及机构事实 |

**bz提供“判定支付条件需要知道什么”的语义。** 原事实决定本单能判断到哪一步；判断是否改变用户任务结果，才决定产品价值。

## 3. 对患者：有解释素材，尚未证明解决自付原因

目前未取得患者原咨询。待验证的任务是：用户能否理解与自己有关的条件、已知事实及该向院方核对什么，而非要求患者自行审病历。

艾普拉唑52.60元、医保外5.26元，同处方有消化性溃疡出血诊断；bz能说明疾病条件有支持，避免把10%误认为病种不符。西甲硅油33元、医保外3.30元，同单有胃肠镜收费；bz将核对方向从诊断名转向用途，但仍缺执行关联。[四链路样例及来源](../steering/费用解释-项目内涵与药品支付备注应用设计-V1.0.md)。

这证明备注可以提出更准确的条件问题；是否减少疑惑、错误理解和重复咨询，未实测。如果只问5.26元怎么算、已有比例足够，不应强塞疾病条款。

罗沙司他跨人10%与全额医保外对照有欠费/住院期间就诊等原记录原因，诊断占位，不能归因为病种限制。同人同码、有效非空备注的严格筛查未见比例波动，不能用当时备注为空的培美曲塞补位。当前仍无目标场景的临床限制归因闭环正例。

患者侧否证：加bz后对原因与下一步的回答未更正确，或误认为已拒付、用药违规、应自行停药。支付限定与临床用药权力有明确区别。[官方答复](https://www.nhsa.gov.cn/art/2021/8/9/art_110_7026.html)。

## 4. 对医保办：价值取决于能否有依据办结

bz可定义核查项、组织证据和检查目录配置，但缺已办结案卷与工时证明。北京规则采用目录备注审核限定支付，说明有业务依据，不证明本产品比已有系统更好。[北京公开规则](https://ybj.beijing.gov.cn/tzgg2022/202609/t20260930_4887205.html)。

四链路157笔/488行含退费无效候选。门诊旧16行加状态4且未退过滤后为12行/7码；门特另1行最终状态待核。16条独立费用关联诊断后变22行，不可直接累加。12行有2行整单基金支付0，因此FeeIn不是基金损失。[只读实库证据](2026-11-04-issue85-adversarial-design-evidence.json)。

潜在有用输出应是“哪项条件缺哪份原记录、谁来核实、拿到后怎样关闭”。西甲硅油核药物—检查关联，卡络磺钠核不能口服记录。拿不到且不改变复核行动时，持续报缺数据只增加负担。

须完成“授权定位原单→必要补证→复核→留依据关闭”，临床补证与技术映射分开办理。无独立确认的冲突不报违规；即使确认冲突，也不能直接推损失。现有系统已能办好的事项，重复生成卡片没有增量。

医保办侧否证：结论质量不改善、总人时不降且无新确认遗漏，或补证和维护增加。总人时包括取数、查阅、临床补证、二审、规则/映射维护，不能只比报告生成秒数。

## 5. 最小比较怎样分离收益

| 版本 | 内容 | 可归因的增量 |
|---|---|---|
| C0 | 实际现有流程，保留原工具及人工政策查阅 | 基线 |
| C1 | C0＋正确绑定版本的bz原文与出处 | 原文就近可得 |
| C2 | C1＋条件事实、来源、缺口及下一步 | 解释与证据组织 |

各组资料相同，新增EMR/LIS事实也等量提供，避免把接入收益归给bz。固定输入/政策版本，分层随机或难度配对，同一人不重复做同一案例；患者与医保办分别评价。

先独立制定正确答案、严重错误、最低有意义改善及样本量/精度依据，再收结果。患者评正确复述/行动，医保办评独立结论一致性、有效关闭和总人时。少样本报分母与不确定性，合成反例只测逻辑，不冒充真实病例；以留出案例防止只为几个药优化。

## 6. 设计修改与结论

运营V3以条件证据卡、复核关闭和三版本比较替代规则入库验收；修正诊断未命中作反证、收费作执行、OR聚合、售价与支付标准、FeeIn作损失、状态过滤及重复关联。保留规则库/标准概念映射，映射仅处理等价差异，政策条件变化必须改规则。

当前可确定：**bz有非数值的信息增量，患者解释有样例、医保办核验有业务依据。** 不可确定：能否减少错误解释、提高办结质量、节省工时，是否值得全量建设。先补原始证据、独立复核和真实任务比较；结果允许患者侧收缩、医保办侧保留，或两侧均停止扩展。

## 7. 本轮验证范围

校验原Excel SHA-256与已存证据一致；按保存的逐行实库快照复算12行/7码、FeeIn 3,859.3120及2行整单基金支付0，核对诊断关联22行与独立费用16行口径；三份文档22处本地引用、版本、表格及修正规则一致性检查通过。本轮未重新查询生产/测试数据库，未修改业务代码；这些校验不等于独立临床审核或用户效果验证。
