# 费用分解后台结构化核对视图

依据：2026-10-19 用户最新三项反馈——起付尽量两行；解释聚焦关键数字、详略得当；后台工作台应结构化、分层展示并统一用语。

## 默认层与下钻层

| 层级 | 内容 | 展示方式 |
|---|---|---|
| 默认 | 起付标准、交易前累计/已交、本笔账面起付 | 第一行，区分年度与周期 |
| 默认 | 医保范围内金额−计算起付＝报销基数 | 第二行，突出基数金额，账面与计算值分别标明 |
| 默认 | 各费用段、基数、基金/个人比例、核实状态 | 分段待遇表，比例口径为补助前 |
| 默认 | 总费用、基金及补助支付、个人支付及占总费用比例 | 实际支付表，金额为主，占比为辅 |
| 按段展开 | 人员类别、结算日、比例关系、规则要求/本单条件/判定、规则版本/确认状态/来源 | 同一费用段下展开；同一时刻展开一段，键盘可操作 |
| 按需展开 | 补助组成 | 实际支付表下的补助明细，说明已计入支付，防止重复相加 |
| 按需展开 | 完整路径、字段解释、所有候选及来源 | 原深入了解入口改为「完整计算依据：结算路径与字段解释」，保留既有能力 |
| 明细层 | 费用项目、目录规则、医保范围内/外金额 | 默认表格；每行条件、算式与重复规则回链保留 |

不再默认重复输出整段「为什么按这个比例」、比例短算式、交易身份及通用解释。核实状态始终在主表可见；候选状态unknown/excluded或条件未确认时不能因运算记录标verified而显示已核实，冲突另列。缺来源、缺金额均不补零或反推。

## 用语与格式

默认列名统一为「医保范围内/医保范围外」「账面金额」「报销基数」「基金比例/个人比例」「规则要求/本单条件/判定」。缺值显示「未取得」；核实状态沿用「已核实/待核实/缺数据/有冲突」；条件判定沿用「符合/不符/未确认」，两者表示不同语义。

汇总和费用明细金额复用 `formatDecimal2` 仅作两位小数展示；算式和来源原文保留原始精度与名称，未调整金额内核、核对阈值、政策参数或公开协议，也未接入模型。新状态只是对既有证据状态的保守展示，不重判业务待遇。
