### 快速原型开发 - 医保AI导办与运营协同平台

**项目背景**:
- 用户需要快速验证产品想法，制作可交互的原型
- 产品定位：医院医保智能工作台，聚合医保接口、事前审核、DRG/DIP、数据中台能力
- 核心场景：结算异常导办、出院前联合质控、运营驾驶舱

**交付成果**:
1. ✅ 高保真可交互原型（Next.js 14 + shadcn/ui）
2. ✅ 4个核心功能模块：
   - AI导办对话（自然语言交互）
   - 结算异常导办（错误码解释+处理步骤）
   - 出院前联合质控（4系统风险聚合）
   - 运营驾驶舱（关键指标监测）
3. ✅ 4角色视图切换（收费员/医保办/信息科/病案室）
4. ✅ 完整的交付文档和演示脚本

**技术栈**:
- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS + shadcn/ui
- lucide-react (图标)
- 模拟数据（无后端依赖）

**开发时间**: 约3小时

**访问地址**: http://localhost:3000

**项目位置**: D:/project/hospital_medical_insurance_agent/prototype

## 关键决策

1. **使用Next.js + shadcn/ui**: 最快速度搭建高质量UI
2. **模拟数据而非真实API**: 快速演示，无需后端开发
3. **4角色视图**: 验证"不同角色需要不同界面"的假设
4. **预设AI回复**: 避免搭建真实LLM，快速演示对话流程

## 经验总结

**快速原型开发模式**:
1. 先理解产品需求和核心假设
2. 选择最快的技术栈（Next.js + shadcn/ui）
3. 使用模拟数据，避免后端依赖
4. 聚焦核心场景，不过度工程化
5. 预留扩展空间，方便后续迭代

**原型验证要点**:
- 必须可交互，不能只是静态页面
- 必须包含真实场景数据
- 必须支持快速演示（预设话术+快捷操作）
- 必须留出反馈收集机制
